# 🎮 ربات تلگرام بازار خرید و فروش اکانت بازی‌های آنلاین

یک ربات جامع تلگرام برای ثبت آگهی خرید و فروش اکانت بازی‌ها (کلش آف کلنز، کلش رویال و...). این ربات تگ بازیکن را با API رسمی سوپر سل چک می‌کند و آگهی تایید شده را همزمان در کانال تلگرام و وب‌سایت وردپرسی منتشر می‌کند.

## 🌟 امکانات کلیدی
- **ثبت‌نام کاربران:** دریافت و ذخیره امن شماره تماس.
- **ثبت آگهی مرحله‌ای (FSM):** جریان گفتگوی مرحله به مرحله برای دریافت دسته‌بندی بازی، تگ، توضیحات، قیمت و عکس.
- **اتصال به API سوپر سل:** تایید خودکار و لحظه‌ای تگ اکانت کلش آف کلنز قبل از ثبت آگهی.
- **پنل مدیریت:** امکان تایید یا رد آگهی توسط ادمین از داخل تلگرام.
- **انتشار چندکاناله:** ارسال خودکار آگهی به کانال تلگرام و درج در وب‌سایت از طریق REST API وردپرس.
- **ویرایش قیمت:** امکان تغییر قیمت توسط فروشنده که به صورت خودکار در کانال و سایت نیز آپدیت می‌شود.

## 🛠️ تکنولوژی‌های استفاده شده
- **زبان:** Python 3
- **فریم‌ورک ربات:** `aiogram` (آسنکرون)
- **دیتابیس:** `PostgreSQL`
- **سرویس‌های متصل:** Supercell API, WordPress REST API, Telegram Channel

## ⚙️ معماری و روند کار
- **رابط کاربری:** تعامل کاربر با دکمه‌های شیشه‌ای و ماشین حالت (FSM).
- **اعتبارسنجی:** ارسال درخواست به `api.clashofclans.com` برای بررسی صحت اکانت.
- **عملیات ادمین:** با کلیک روی "تایید"، ربات آگهی را در کانال پست کرده و با ارسال درخواست HTTP به سایت وردپرس، آن را ثبت می‌کند.
- **یکپارچگی داده‌ها:** استفاده از تراکنش‌های امن SQL برای مدیریت وضعیت آگهی‌ها.
